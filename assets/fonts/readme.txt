NMD19 — FUENTES REALES (lista de compra + instrucciones)
=========================================================

El sitio usa ahora substitutos gratis. Para que sea idéntico al Figma
hay que comprar 2 fuentes y poner los .woff2 en ESTA carpeta.

------------------------------------------------------------------
1) RADIO GROTESK  (texto / botones / párrafos)   ← la barata
------------------------------------------------------------------
  Foundry : Pangram Pangram
  Comprar : https://pangrampangram.com/products/radio-grotesk
  Licencia: comercial desde $40 USD (cubre la familia)
  Descarga: el paquete WEB (woff2).
  Pesos   : ideal Regular + Medium + Bold. Mínimo Regular + Bold.
  Renombra a:
     RadioGrotesk-Regular.woff2
     RadioGrotesk-Medium.woff2   (opcional)
     RadioGrotesk-Bold.woff2

------------------------------------------------------------------
2) MĀNUKA  (los títulos gigantes: SHOP, BOOK, etc.)   ← la cara
------------------------------------------------------------------
  Foundry : Klim Type Foundry
  Comprar : https://klim.co.nz/buy/manuka/
  Licencia: WEB FONT (pago único, sin vencimiento). El precio se
            configura en su página según el peso.
  Peso    : MĀNUKA BLACK (el más grueso). Con ese basta.
  Descarga: el archivo web (woff2).
  Renombra a:
     Manuka-Black.woff2

------------------------------------------------------------------
QUÉ HACER
------------------------------------------------------------------
  1. Compra las 2.
  2. Baja el paquete WEB (woff2) de cada una.
  3. Suelta los archivos en esta carpeta (assets/fonts/) con los
     nombres de arriba. Si vienen con otro nombre, déjalos igual y
     avísame: yo los renombro.
  4. Dime "listo" → yo enlazo fonts.css en todas las páginas y
     verifico que se vean idénticas al Figma.

(Nota: una tercera fuente menor del Figma, Lunchtype25, está como
'Oswald' gratis. Se usa muy poco; la dejamos así salvo que quieras
comprarla también.)
